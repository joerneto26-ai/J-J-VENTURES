# J&J VENTURES — Prospección Outbound B2B

Sistema integral de adquisición comercial y prospección outbound para empresas B2B, industriales y de logística en México.

## 🚀 Contenido del Repositorio

- **`index.html`**: Landing Page de alta conversión construida con Tailwind CSS, Alpine.js y Lucide Icons. Incluye:
  - Hero de alto impacto con botones estilo píldora interactivos.
  - Diseño alternado de secciones oscuras y blancas (estilo Ronin Socials).
  - Cuestionario de calificación de 8 pasos.
  - Selector de fecha y hora nativo (100% white label) integrado directamente con Google Sheets y Google Calendar.
- **`google_apps_script_code.js`**: Backend serverless para Google Apps Script que registra leads en Google Sheets y agenda eventos con enlaces de Google Meet.
- **`paquetes_lead_generation_mexico.md`**: Estructura de paquetes, costos de infraestructura (Inframail, IONOS, NeverBounce), precios psicológicos y cláusulas legales.
- **`Paquetes_y_Costos_LeadGen_JJVentures.pdf`**: Documento ejecutivo de precios y márgenes.
- **`banner_hueso_v1_editorial.png`**: Banner oficial para perfil de LinkedIn (1584 × 396 px).

## 📦 Despliegue en Vercel

1. Importa este repositorio en [Vercel](https://vercel.com).
